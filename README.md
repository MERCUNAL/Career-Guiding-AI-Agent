<h1>Career-Guiding-AI-Agent</h1>
This repo consists of two logics: 1] Using LLM Models thorugh API for generating questions and final verdict
<br>
2] Generating predecided questions and final verdict through the LLM either locally hosted or via API
<br>
Setup Requirements: <br>
Creating and activating virtual Environment: ``` python -m venv venv 
venv/Scripts/activate``` <br>
Install all the libraries and packages: 
``` pip install -r requirements.txt```
Add a .env file and setup the API key:
``` GROQ_API_KEY = ```
Run the streamlit file app.py:
``` Streamlit run app.py ```
