# Career-Guiding AI Agent

A career guidance application that assesses users through a series of questions and provides personalized career recommendations using LLMs.

## Features

- Dynamic question generation using LLM APIs.
- Predefined question-based assessment.
- Final career guidance verdict generated by an LLM.
- Support for both locally hosted models and API-based models.
- Interactive user interface built with Streamlit.

## Assessment Modes

### 1. LLM-Generated Questions
- Questions are dynamically generated using an LLM API.
- User responses are analyzed in real time.
- A personalized career guidance verdict is generated at the end.

### 2. Predefined Questions
- Uses a fixed set of career assessment questions.
- User responses are evaluated by an LLM.
- Supports both locally hosted and API-based LLMs for generating the final verdict.

## Installation

### Clone the Repository

```bash
git clone <repository-url>
cd Career-Guiding-AI-Agent
```

### Create and Activate a Virtual Environment

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/macOS**

```bash
python -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

## Environment Variables

Create a `.env` file in the project root directory and add your API key:

```env
GROQ_API_KEY=your_api_key_here
```

## Running the Application

```bash
streamlit run app.py
```



## Project Workflow

1. User starts the assessment.
2. Questions are either:
   - Dynamically generated by an LLM, or
   - Selected from a predefined question set. --current workflow
3. User submits responses.
4. Responses are analyzed by the selected LLM.
5. A final career guidance report and recommendations are generated.
